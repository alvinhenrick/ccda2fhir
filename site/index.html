ccda2fhir

Convert C-CDA documents to FHIR R4, written in Rust. A pure library first, with a command line tool, an HTTP service and a WebAssembly build on top.

Live demoDrop a C-CDA file and see the FHIR bundle. It runs in your browser; nothing is uploaded. DocumentationCoverage by element, USCDI status, design decisions, lessons and the changelog. API referenceRust documentation for the library crates. Source on GitHubMIT licensed. Issues and pull requests welcome.

What it does

  • Maps USCDI v1 and v3 data classes to FHIR R4 (4.0.1) and claims US Core 6.1.0 profiles only where the required data exists.
  • Never invents values and never drops data silently: every judgment call is listed in a report with a stable code.
  • Deterministic output, checked against the HL7 validator in CI on synthetic fixtures and the HL7 C-CDA examples.
  • Optional JWT authentication on the service; a strict Content-Security-Policy on the built-in page.

Use it

cargo run --release -p ccda2fhir-server -- convert ccd.xml > bundle.json
cargo run --release -p ccda2fhir-server -- serve --bind 127.0.0.1:8080   # web page at /, API at POST /convert
Use synthetic or de-identified data only until your own security and compliance review is done. See the Security page in the documentation.
