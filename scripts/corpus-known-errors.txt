# Validator errors on the HL7 example documents that are not converter bugs. One regular
# expression per line, matched against the normalised error text (see corpus_gate.py).
# HL7's example weights use 3141-9 (Body weight Measured). The validator applies the FHIR bodyweight
# profile to such a vital sign, and that profile insists on 29463-7. We do not add a code the
# document does not carry.
BodyWeightCode: magic LOINC code 29463-7 required
# CPT is licensed by the AMA, so its displays are never bundled (ADR 0027), and the validator's
# CPT edition does not list some retired codes the examples use.
Wrong Display Name .* for http://www.ama-assn.org/go/cpt#
Unknown code '99241' in the CodeSystem 'http://www.ama-assn.org/go/cpt'
# The example documents themselves use these wrongly: 54522-8 is LOINC but sent as SNOMED,
# 57113-1 and C-CDAV2-DDN are not LOINC codes, and 3141-9 / 59408-5 are alternatives to the
# vital-sign codes the base FHIR profiles insist on.
Unknown code '54522-8' in the CodeSystem 'http://snomed.info/sct'
Unknown code '57113-1' in the CodeSystem 'http://loinc.org'
Unknown code 'C-CDAV2-DDN' in the CodeSystem 'http://loinc.org'
OxygenSatCode: magic LOINC code 2708-6 required
